# Noëlle

Noëlle est une application qui permet graçe à l'import d'un csv de faire un couplage pour le secret santa. une fois le tirage fait , elle envoi un mail a chacun pour lui divulguer qui elle devra gâter.

Projet créé avec ADA (stack Vue 3 + Node.js/Express + SQLite, DSFR). Fiche projet :
