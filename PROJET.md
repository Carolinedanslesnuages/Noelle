# Noëlle

**Objectif :** Noëlle est une application qui permet graçe à l'import d'un csv de faire un couplage pour le secret santa. une fois le tirage fait , elle envoi un mail a chacun pour lui divulguer qui elle devra gâter.
**Stack :** Vue 3 + Node.js (Express) + SQLite, DSFR (modèle ADA `vue-node`)
**DSFR :** oui
**Créé le :** 2026-11-19 par Carolinedanslesnuages

## Lancer le projet
| Action | Commande |
|---|---|
| Lancer l'API | `cd api && npm run start:dev` |
| Lancer le front | `cd front && npm run dev` |
